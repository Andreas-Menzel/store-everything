# Store Everything

A self-hosted personal cloud for individuals and small groups that stores files of every type — and makes them findable. Like Google Drive on your own hardware, but with search as the actual product: exact search that returns the position inside a file, and semantic search that finds content by meaning.

Every uploaded file is analyzed by pluggable extractors (OCR, transcription, object detection, and more) running as local Docker containers. By default, everything — including AI inference — runs locally with zero external network calls.
